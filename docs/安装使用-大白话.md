# 拆解对标 Skill：大白话安装使用说明

> 正式版说明见根目录 `README.md`。这份是给"不想读术语"的人准备的。

## 一、这东西是干嘛的？

一句话：**你把拆解照片、零件清单发给 Copilot，它帮你整理成「机械 / 材料 / 成本 / 工艺」四张表的分析报告**，还会告诉你哪些结论目前证据不够、缺什么数据才能下结论。

它不会瞎编：没给照片就说"没有实物证据"，只列待确认清单。

## 二、开始之前，你需要有

| 东西 | 必须吗 | 说明 |
|---|---|---|
| VS Code + GitHub Copilot | 必须 | 能正常打开 Copilot 聊天框就行 |
| Python | 可选 | 只在想跑"零件清单自检脚本"时才需要，没有也不影响分析 |

## 三、安装（两种方式，选一个就行）

### 方式一：把整个文件夹当工作区（最省事，推荐）

1. 打开 VS Code
2. 菜单 **文件 → 打开文件夹**，选中 `c:\cjn\ev-teardown-analysis`
3. 完事，不用装任何东西

原理：skill 文件放在这个文件夹的 `.github/skills/` 里，VS Code 打开这个文件夹时会自动认出来。

**适合**：就在这个项目里用。

### 方式二：装到自己账户下（换别的项目也能用）

1. 按 `Win` 键，输入 `powershell`，回车，打开蓝色窗口
2. 把下面两行整段复制进去，回车：

```powershell
New-Item -ItemType Directory -Force "$env:USERPROFILE\.copilot\skills" | Out-Null
Copy-Item -Recurse -Force "c:\cjn\ev-teardown-analysis\.github\skills\ev-teardown-benchmark" "$env:USERPROFILE\.copilot\skills\"
```

3. **重启 VS Code**（不重启认不到）

原理：把 skill 复制到了你的个人目录 `C:\Users\你的用户名\.copilot\skills\`，以后不管打开哪个项目都能用。

**适合**：想在别的项目里也用这个 skill。

### ⚠️ 放错位置就没用

skill 只待在这几个地方才会被认出来：

- 项目里的 `.github/skills/`、`.agents/skills/`、`.claude/skills/`
- 你账户下的 `~/.copilot/skills/`

放到别的目录（比如 prompts 目录）是**不会**被识别的。

## 四、怎么用（三步）

### 第 1 步：确认装好了

在 Copilot 聊天框里输入一个 `/`，看下拉列表里有没有 `ev-teardown-benchmark`。有 → 装好了；没有 → 回到第三节检查装没装对位置。

### 第 2 步：把材料喂给它

它吃三样东西，有多少给多少，直接拖进聊天框：

- **拆解照片**（拖文件进去）
- **零件清单**（CSV / Excel，给文件路径或截图都行）
- **车型信息**：什么车、哪一年、什么配置、哪个部位（比如"EX90 Ultra 2025 后逆变器"）

### 第 3 步：开口要结果

两种叫法随便挑：

**叫法 A（斜杠命令，最稳）：**

```
/ev-teardown-benchmark Volvo EX90 Ultra MY2025 后逆变器，零件清单见 samples/ex90-rear-inverter-parts.csv
```

**叫法 B（直接说人话）：**

> 帮我分析这个后逆变器的拆解，照片和清单都发你了

说人话也能触发——只要描述里带"拆解""对标""逆变器""OBC""DC-DC"这类词，它会自动加载。

### 它会给你什么

默认给**精简版**：四张表 + 结论 + "还缺什么证据"清单。

想要逐个零件深挖的完整版，在请求里加一句 **"要完整版"**。

## 五、有 CSV/Excel 清单？建议先跑个自检（可选）

在 VS Code 里按 `` Ctrl+` `` 打开终端，跑：

```
py .github/skills/ev-teardown-benchmark/scripts/part_table_check.py samples/ex90-rear-inverter-parts.csv
```

（Mac/Linux 把 `py` 换成 `python3`）

它会告诉你：一共多少件、总重多少、哪些字段填错了、哪些件缺数据、清单里是不是漏了功率模块这类关键件。

**把输出整段贴给 Copilot**，分析会更准——它就是靠这个输出发现"清单里没出现功率模块"这种漏采问题的。

## 六、常见问题

**Q：输入 `/` 看不到这个 skill？**
- 方式一装的：确认打开的是 `ev-teardown-analysis` 文件夹**本身**，不是它的上级目录
- 方式二装的：确认复制的是整个 `ev-teardown-benchmark` 文件夹（不是里面的单个文件），然后重启 VS Code

**Q：它开始编造内部结构？**
说明证据没给够。补照片或清单；或者直接说"没有实物证据，只列待确认项"。

**Q：分析太长/太短？**
默认精简。要细的加"要完整版"；嫌长的直接说"只要三张表"。

**Q：能出 Word / PDF 吗？**
默认只出 Markdown / Excel。要别的格式，在请求里明说。
